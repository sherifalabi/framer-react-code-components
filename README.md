Framer React Code Components

A growing collection of reusable Framer code components, React overrides, and interactive UI experiments built to create polished, responsive web experiences.

Created by Sherif Alabi, Design Engineer and founder of CraftVra.

About

This repository explores the intersection of design and development through practical, reusable code for Framer projects.

The focus is on thoughtful interactions, clean implementation, responsive behavior, and details that make digital experiences feel refined.

What you’ll find

* Framer Code Components — Custom components for extending Framer’s native capabilities.
* React Overrides — Reusable behavior and interaction patterns for Framer layers.
* Interactive Experiments — Small explorations in motion, interface behavior, and frontend development.
* Reusable Patterns — Practical solutions that can be adapted across different projects.

Content will be added progressively, with individual examples and usage instructions as they become available.

Getting started

These examples are intended for use in Framer projects.

1. Browse the repository for a component or override.
2. Open the relevant source file and review its requirements.
3. Add the code to your Framer project’s code editor.
4. Follow the individual example’s setup instructions and connect it to your design.
5. Test the result across screen sizes and interaction states before publishing.

Some examples may require additional setup or dependencies. Check the instructions provided with each example.
